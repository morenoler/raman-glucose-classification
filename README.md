# Классификация рамановских спектров сахарных смесей

Задача: определить по рамановскому спектру, присутствует ли глюкоза в смеси сахарозы, фруктозы, мальтозы и воды. Метка берётся из рецептуры лунки: `Glucose [ul] > 0`. Это исследование на открытом наборе [Raman_Sugars](https://github.com/Alvaro-FG/Raman_Sugars), а не медицинский или промышленный классификатор.

## Постановка и проверка

В наборе есть 1 960 спектров, измеренных с экспозицией 5 с, и 7 840 спектров тех же смесей с экспозицией 0,5 с. Для каждой физической лунки снято несколько повторов. Если разделить отдельные спектры случайно, повторы одной лунки попадут и в обучение, и в тест. Такой тест будет слишком простым.

Поэтому разделение сделано **по лункам** с сохранением доли классов: 183 лунки в обучении и 62 в тесте. Модели обучаются только на длинной экспозиции. Затем они оцениваются на отложенных лунках при длинной и короткой экспозиции. Использован фиксированный `random_state=42`; список источников и контрольные суммы закреплены в [`src/fetch_data.py`](src/fetch_data.py).

| Модель | Balanced accuracy, 5 с | Balanced accuracy, 0,5 с | ROC AUC, 0,5 с |
|---|---:|---:|---:|
| Частый класс | 0,500 | 0,500 | 0,500 |
| Логистическая регрессия | **1,000** | **0,967** | **0,995** |
| Случайный лес | 0,978 | 0,678 | 0,970 |

На короткой экспозиции у логистической регрессии 24 ложных обнаружения глюкозы и 31 пропуск на 1 984 спектрах. Случайный лес чаще ошибочно отмечает глюкозу при шумном сигнале. У простого классификатора F1 высокий из-за преобладания положительного класса; поэтому в сравнении на первом месте balanced accuracy.

## Методика

1. Привязка столбцов спектров к строкам метаданных по `filename`; метка — наличие глюкозы в рецептуре.
2. Обрезка до области 400–1800 см⁻¹, 517 точек спектра. SNV-нормализация отдельно для каждого измерения.
3. Разделение по `plate + row + col` перед обучением. Масштабирование признаков для логистической регрессии обучается только на тренировочных спектрах.
4. Сравнение с `DummyClassifier` и случайным лесом. Метрики: balanced accuracy, F1, precision, recall, ROC AUC и матрицы ошибок.

Графики и полный набор метрик создаются одним запуском. Сырые измерения не копируются в этот репозиторий.

## Воспроизведение

Требуется Python 3.10+. Загрузка четырёх CSV занимает около 120 МБ.

```bash
python -m venv .venv
# Активируйте окружение обычным способом для вашей ОС.
python -m pip install -r requirements.txt
python src/fetch_data.py
python src/train.py
python src/make_report.py
```

Результаты появятся в `output/`. Страница и нужные для неё графики также копируются в `docs/` для GitHub Pages. Скрипт загрузки проверяет SHA-256 каждого файла. Если исходный репозиторий станет недоступен, данные и описание формата находятся по указанной выше ссылке на `Raman_Sugars`.

## Ограничения

Измерения короткой и длинной экспозиции относятся к тем же приготовленным лункам. Группа тестовых лунок исключена из обучения, но это всё ещё один эксперимент с одним прибором и одной процедурой подготовки образцов. Результаты не показывают качество на другом спектрометре, новой партии растворов или веществах вне четырёх выбранных сахаров. Доля положительного класса в обучении около 72%; одна accuracy скрыла бы ошибки на отрицательном классе.
